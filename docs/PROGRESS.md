## v0.2 演示系统交付

本轮按用户要求：一天冲刺目标、四角色、完整演示主线、通用审批设计器；财务前端注明暂无功能；钉钉/飞书真实接口。原始crm与partneros-crm目录保留，代码在tb-crm功能分支，草稿PR #1未合并，未进行公网部署或生产验收。

已实现：

- admin / manager / sales / boss四类登录、对应工作台和菜单；本人、团队、本租户范围，老板默认只读业务。
- 客户/联系人增改查、公海领取/退回/主管分配、线索转客户、跟进、行动、商机阶段/产品报价。

- 通用审批设计器：文本/数字/日期字段、顺序节点、金额条件、指定人/唯一角色/部门负责人、版本草稿/发布/预演。
- 业务提交显示设计器的必填字段；审批节点快照、当前节点限制、禁止自审、驳回与撤回、站内通知。
- 写入参数白名单、关联对象与权限校验、Serializable事务、持久化请求幂等、乐观时间戳和审计。
- Web、工具及MCP共用客户可见范围和Workspace业务服务；权限撤销按实时JWT用户加载生效。
- 14类业务资源及审批流程/表单/动作的契约目录、7个只读MCP工具及能力资源；不开放智能体金融写入。
- 财务记录与功能页面展示合成数据，禁用真实处理并标注“演示系统，暂无功能”。
- 钉钉/飞书固定官方域名的真实令牌、部门和成员分页预览接口；按租户绑定凭证、错误与超时处理。
- 本机MySQL 8.4.11、启动器、演示账号说明、独立数据测试和新建干净副本复演；旧库保留。
- 未加固旧原型业务REST入口停用并从OpenAPI隐藏；旧定时任务默认关闭。
