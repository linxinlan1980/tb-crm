# CRM建设路线

## M0 工程与权限基线（当前）

可重复安装、migration、构建、测试；接入真实MySQL验证；客户只读能力目录与工具接口；保留原稿。

## M1 客户经营闭环

客户与联系人创建/编辑、归属与公私海领取、跟进与行动计划。统一DTO、行级/字段权限、并发领取保护。能力契约与网页共用，验证多租户真实数据库场景。

## M2 智能体执行基础

独立智能体身份、用户委托与限时授权；MCP适配；能力输入输出结构；持久化执行记录；dry-run/预览；写入幂等与版本检查；有范围的自动执行与必要审批。

## M3 商机到合同

阶段推进、报价口径、审批流及业务回调；合同状态与七类节点模板；可靠事件。付款比例等业务冲突记录为待确认，不能由代码自行认定。

## M4 交付到回款

里程碑证据、验收、开票、收款核销、预收、账龄；金额明细重算；作废与补偿；全链路边界和并发测试。

## M5 知识与外部连接

有来源与版本的合同/附件/规则读取；文档证据定位；钉钉、用友、邮件真实接口；按租户隔离凭证；同步与对账。

## M6 产品验收

移动适配、性能、恢复演练、用户试用、导入已授权数据、正式验收后上线。每阶段以可演示链路和测试证据验收，不按文件数量推算完成率。
