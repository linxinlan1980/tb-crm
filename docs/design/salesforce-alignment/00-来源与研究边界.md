# Salesforce研究证据与边界 v1.0

日期：2026-11-15；状态：设计候选；执行负责人：Codex；产品负责人：林昕岚。

目标是尽量完整对齐Salesforce销售CRM的业务能力和操作模式。研究范围为Sales Cloud / Agentforce Sales、相关平台配置与销售收入生命周期。其他行业云、Service/Marketing/Commerce全产品及Salesforce内部实现不属于“全部销售CRM”的同义词。扩展能力进入完整待办，不从范围中静默删掉。

依据为官方帮助、Trailhead和开发文档；已阅读相关文字及公开配图入口，未登录Salesforce租户逐项实操、未完成所有Trailhead挑战、未测试响应时间和转化效果。因此不能宣称“已完整掌握Salesforce全部产品”或“功能已1:1实现”。将公开能力、我们现有可达入口和拟建目标分别标记。企业版本、地区和附加许可仍需按实际租户核验。新Agentforce配置页面部分限定sandbox，不把该配置流程当作现网通用步骤。

“照搬”在工程上落实为业务能力及通用交互模式的充分对齐；产品保留自身品牌，不复用竞品源码、商标或专有界面素材。本轮只编写设计与工程计划，无业务上线或数据库变更。
