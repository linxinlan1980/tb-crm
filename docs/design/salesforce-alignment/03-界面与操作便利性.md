# 界面与操作便利性设计 v1.0

本文件为拟建规范，非当前界面验收结论。U00—U16是设计编号，不是已实现路由。参考S01—S06、S08、S13—S15、S22。品牌、色彩、文字和图标自行设计，不复制Salesforce视觉资产。

## 0. 蓝白灰视觉规范（用户已指定）

|用途|色值|规则|
|---|---|---|
|主蓝|#2563EB|主按钮、选中导航、关键链接和当前阶段|
|主蓝悬停|#1D4ED8|主操作悬停；焦点另加可见轮廓|
|浅蓝|#EFF6FF|选中背景、解释信息和轻量标签|
|内容白|#FFFFFF|卡片、表格、表单、弹层和顶部导航|
|背景灰|#F3F5F8|页面底色，拉开内容层级|
|边框灰|#D8E0EA|分隔、输入框和表格边界|
|正文深灰|#1F2937|主要文字，避免浅灰小字承载关键事实|
|辅助灰|#64748B|辅助标签、时间和次要说明|

默认浅色主题，不增加彩虹图表或大面积渐变。报错、警告和成功可用少量语义强调色，但必须同时有文字/图标，不只靠颜色表达。优先保持白底可读、蓝色主动作清楚、灰色层级克制。按钮/文本对比度、禁用态、焦点和色盲可辨性在UAT检查，未检查前不声称符合无障碍认证。配色写成设计token并统一组件引用。

## 1. 整体信息架构

全局顶部：企业/应用切换、跨对象搜索、快捷新建、最近访问、通知、个人设置。侧栏分“我的工作 / 客户经营 / 销售推进 / 交易交付 / 分析 / 管理”，各角色按权限显示。常用入口支持收藏，页面URL可直达；右侧AI按当前记录展开。

列表负责检索和批量管理，详情负责完成业务任务；复杂商机/合同使用独立详情页。抽屉用于快速查看和简单创建，不能在760px抽屉塞下完整商机工作区。返回列表必须保留页码、筛选、排序、列宽和滚动位置。记录不存在、被删除、权限撤回分别反馈，但不泄漏不可见记录名称。

## 2. 三个核心页面草图

### U01 销售工作台

```text
全局搜索                         快捷新建   通知   我的
我的工作   客户   商机   交易   分析
[今天/本周] [我的/团队权限范围] [视图]
今日待办  逾期行动  待联系线索  待推进商机
优先事项                              本期目标
客户A·方案会将在明天举行               目标/已赢单/承诺/缺口
依据：会议记录，准备人李某               点击数字钻取同口径明细
[查看客户] [生成会前简报]
商机B·下一步已7天未更新
依据：最后更新日期 [更新下一步]
今天的日程/任务       最近客户          AI草稿与执行结果
```

信号的触发依据必须可点开；“7天”等阈值为可配置规则，非机器学习结果。规则与AI建议分开标注。行动按钮完成后卡片更新/消失，失败保留输入和原因。管理员工作台显示配置与运行事项，老板显示经营风险和周期变化，不复用销售的日程清单充数。

### U04 客户360

```text
客户A  [重点客户]  负责人/团队  最近跟进  下次行动
[记录拜访] [新建商机] [安排任务] [更多]
概览  活动时间线  联系人  商机  合同交付  服务  历史
左：客户核心资料    中：近期活动/待办      右：AI简报/证据
组织层级与联系人    结果、附件、作者       未知信息清单
当前商机与金额      完成任务→安排下一步    建议与变更预览
```

客户下新建商机自动带入customerId，既有客户不可无提示切换。联系人、合同、项目可预览并直达；返回仍保留当前客户。时间线按事件时间显示并区分录入时间，历史补录明确标记。敏感字段受权限控制，不能只靠隐藏组件。

### U05 商机工作区

```text
商机B   金额/预计成交日/负责人/预测类别/下一步
发现→需求→方案→报价→谈判→待签约    [输单] [阶段变更]
当前阶段关键字段      完成要求及指引       缺失项[补齐]
[记录沟通] [安排会议] [新建报价] [申请支持]
左：关键人及角色      中：活动/方案/报价     右：风险与AI建议
决策者/评估者/使用者  关联文件和审批版本    理由/来源/数据时间
```

不支持拖拽作为唯一推进方式。拖拽/按钮/API使用同一服务端校验；缺信息时先收集，再确认移动，失败返回原列。商机金额、日期变化显示旧→新及作者时间；即使不是AI修改也应有业务历史。

## 3. 便利性规范

|编号|要求|验收方式|
|---|---|---|
|UX01|常用主动作在首屏；次要动作收进更多菜单|桌面1440/1280视口核对首屏动作；手机固定底部主动作|
|UX02|父子记录自动带入关联对象|从客户新建跟进/商机，从商机建报价，均不需重选父对象|
|UX03|关联对象可搜索、预览、直达并返回|超过100条仍可找到指定记录；返回保留列表位置|
|UX04|个人/团队视图可保存，条件显示为标签|刷新和重新进入后条件一致；共享视图权限可验证|
|UX05|列表、看板和汇总共用查询口径|同一筛选下金额、数量与导出完全勾稽|
|UX06|行内编辑与批量操作先预览|显示条数、变化、失败项；部分成功策略显式选择|
|UX07|保存成功提供查看结果和继续操作|单据生成后可直接进入，不只提示“去对应模块查看”|
|UX08|表单分组、渐进显示、草稿恢复|网络失败不清空；敏感草稿不保存在不受控公共存储|
|UX09|字段错误定位、服务错误可恢复|不只弹toast；聚焦首个错误，说明原因和可修复操作|
|UX10|并发冲突显示服务器新值与本地草稿|用户可比较并重新提交，禁止静默覆盖|
|UX11|无数据/无匹配/无权限/连接失败分开|空态给正确操作；不展示虚假演示成功|
|UX12|金额有币种、日期有时区/期间、术语一致|预测、合同、应收、回款、核销、收入不混名|
|UX13|AI结果有来源、差异、批准/拒绝和执行状态|未批准无写入；失败不呈现已完成；过期建议可重生成|
|UX14|常用快捷键可发现且不与浏览器冲突|快捷键帮助、键盘焦点、Esc退出、焦点回到原按钮|
|UX15|触控与读屏可完成主线|无悬浮专属操作；按钮可读名称，错误与状态可读|
|UX16|大列表服务端分页及异步导出|全选明确是当前页还是全部查询；分页改变不偷换范围|
|UX17|危险动作说明业务影响和限制|丢单、转交、撤销/作废有原因；不可撤回的外发明确提示|
|UX18|所有页面显示真实状态|演示/正式、未连接/同步中/失败、规则/AI建议均明确|

操作目标属于拟验收目标，尚无实测成绩：客户详情进入后，记录跟进并安排下一步应能在同一流程完成；“完成并安排下次”减少重复建任务；商机周会可在管道页查看风险、编辑日期/下一步并留下变更依据。点击数、耗时及错误率先按05基线测量再锁定，不能捏造提升百分比。

## 4. 其他界面关键规则

- U06：默认本期开放商机；列显示金额、日期、类别、最后活动、下一步、阶段时长和变化。风险可组合筛选，选中行在侧栏处理，不丢上下文。看板显示全查询汇总，不把前100条当全部。
- U07：默认单类汇总，累计汇总单独开关和公式说明；所有卡片可钻取。销售提报值、主管调整值并列，不用一个数字覆盖双方意见。
- U08：报价行支持键盘连续录入与查找产品；总价实时预览但服务器最终计算；版本比较突出单价、数量、折扣、税率和付款条件差异。
- U09：分期表可预览总额/尾差/触发条件；已核销计划冻结相关字段，只能走更正。交付状态独立于商机赢单。
- U10：字段、筛选与分组在左，预览在右；保存前验证权限和估计查询范围；导出条件写入文件说明。
- U11/U12：配置发布先预演“这个销售能看什么/这份合同会走谁”；未发布配置不影响已运行实例。
- U13：步骤为上传→字段匹配→重复处理→预演→执行→对账；进度按已处理行数和失败数，不按假进度条。
- U15：记录页侧栏和全局入口共用建议；批量建议逐条确认或明确批次范围。批准后客户/商机改变时提示重新预览。
- 手机优先U01/U04/U05简版、跟进录入、任务和审批；报表设计器等复杂页面可先提供只读，明确能力差异，不能声称桌面全量已移动适配。

## 5. 信息呈现与验证

正文优先显示业务名称，内部ID仅在审计/技术详情出现；JSON不直接作为普通用户结果。加载展示骨架/实际状态，不反复闪空列表。每个主页面设计空、加载、失败、无权、数据过期和小屏状态。布局使用现有Ant Design能力组合，保持中文字段、合理密度和可见焦点；性能指标需按05实测。

review.html仅展示U01/U04/U05/U06/U15的方向，使用合成数据与本地交互，不是完整高保真设计或实际业务系统。其他页面以本规范和后续里程碑细化稿为准。
