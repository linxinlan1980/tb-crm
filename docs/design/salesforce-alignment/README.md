# Salesforce销售CRM对齐设计包 v1.0

2026-11-15 · 设计候选 · 未实现/未上线。本轮按产品负责人“尽量完整对齐Salesforce、补操作便利性、形成设计与工程计划”的要求编写。

## 阅读顺序

1. [来源与边界](00-来源与研究边界.md)：26项官方来源，区分公开证据、原型和可用功能。
2. [功能对齐矩阵](01-功能对齐矩阵.csv)：48项能力，逐项编号、现状、目标、优先级、页面及验收对应。
3. [产品设计PRD](02-产品设计PRD.md)：业务、角色、主线、状态与异常。
4. [界面与操作便利性](03-界面与操作便利性.md)：17类页面、页面草图、交互标准和操作目标。
5. [工程实施计划](04-工程实施计划.md)：架构、数据、接口、13个里程碑、依赖和交付门槛。
6. [验收与发布](05-验收与发布.md)：48项验收、性能验证、迁移/回退、试运行。
7. [可点击设计预览](review.html)：合成数据，展示5个关键页面结构；只是设计示意，不连接实际CRM。

8. [本轮检查记录](06-本轮检查记录.md)：文档、页面示意和实际功能验证边界。

## 产品方向

以完整销售业务为目标，按用户任务推进。保持AI可调用、本地部署、四角色入口、通用审批及已有交付售后能力；借鉴Salesforce的工作台、记录页、活动时间线、Path、管道检查、预测、元数据和Agentforce行动模式。

## 本轮完成边界

完成研究整理、设计、追踪矩阵和工程计划。没有完成Salesforce全生态实操，也没有把拟建功能计为实现。P3扩展能力全部列入，进入建设前补专项设计；不承诺与Salesforce全部产品或内部架构1:1一致。
