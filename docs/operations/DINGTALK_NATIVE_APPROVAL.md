# 局域网CRM与钉钉原生审批

## 工作方式与当前范围

在“集成与同步 → 钉钉原生审批（局域网）”配置。合同先进入CRM通用或签流程，申请人核对完整预演并确认发送，审批人在钉钉原生页面处理；本机通过出站HTTPS读取结果，无需将CRM公开到互联网，也不需要群机器人或入站回调。可开启每60秒读取已发送记录的结果。

当前为逐单确认发送，不是创建合同后无人核对自动外发。新合同自动进入CRM审批与是否发送到钉钉是两项独立设置。手机在外可处理钉钉单据；完整CRM网页仍需局域网或另行配置VPN/HTTPS入口。

仅支持本人DWS授权、本人发起的单步固定人员人工或签合同。其他申请人需要各自本人授权，以及与实际可审批人员一致的钉钉模板；不能借管理员账号冒充销售提交。申请人不审批自己的申请。多级流、会签、外部转审、附件发送、飞书原生审批及企业应用统一代发暂不在此连接范围。

## 配置与人员对照

1. 本机按钉钉官方方式安装及授权DWS，模板管理需要支持相应命令的版本（本次验证v1.0.68）。可在公司私有配置设置DWS_OA_BINARY，日程和组织同步继续使用既有DWS_BINARY。可执行路径和profile不接受HTTP输入。
2. 在通用审批设计器发布单步“多人或签（任一同意）”合同流程；内部业务规则可选择新合同立即提交此流程。
3. 在钉钉建立匹配的人工固定人员或签模板，禁用申请人自动审批。不得使用只允许单选的自选节点冒充多人或签。模板人员编号来自真实通讯录对照，不用姓名作为唯一身份。
4. 设置CRM流程、钉钉processCode、本人真实所属发起部门、生效日期与自动读取选项，保存后点击“验证真实模板、人员和部门”。组织与人员的完整对照在“钉钉组织同步”页维护；每张单的预演再次核对实际审批人。

模板须包含9个必填文本控件：本地审批编号、合同编号、合同名称、客户名称、签约主体、合同金额、CRM申请人、审核指纹、说明。说明承载合同类型、币种、税率、付款条款和备注，不截断后发送；超出承载限制会阻断。其他必填字段不能静默省略。

## 发送与审批结果

选择本人待审批合同，读取最新表单Schema、模板和流程预测，核对实际人员、完整字段与金额。预演有效10分钟。点击发送仍需确认同一份内容；服务端再检查本地版本、授权、模板和预测，并在外部写入前持久认领该申请。

同一审批只允许一个有效外部连接。发送期间及已连接后，本地通过、驳回、转审、撤回被阻止，避免产生两个审批结果来源；审批中心显示钉钉处理指引。钉钉撤销经读取核定后，才释放本地操作，不伪造已撤回历史。

读取结果时验证企业及本人绑定、模板、实例编号、发起部门、完整表单及指纹、实际任务人员与人工操作记录。只把经核定的实际决定交给同一通用审批状态机；当前人员权限及源单版本重检，审批事件、同组跳过、业务回调、通知、回执与审计事务完成。审批不会自动签约、开票或制造收款。待办勾选完成不能代替审批。

## 失败与边界

网络中断或创建未返回确定编号时，记为“结果不明”，禁止自动重发；创建成功但回读或源版本核对不通过时暂停。管理员应按模板、申请人、时间与审核指纹核对钉钉记录，不能删除本地记录后重发。创建结果不明时先只读查询同一本人授权下、同模板和发送认领时间窗口内的已发起记录；必须分页完整、唯一匹配审核指纹，并核定全部字段、部门和任务人员，才能链接原实例。页面提供“只读查找并核回”；失败保持结果不明，不重复创建，也不接受用户填入的外部实例号。原创建回执和核回证据仅保留在本机私有记录。

自动读取只处理已确定发送的连接，不批量补发历史。历史资料补录合同明确禁止外发。角色、人员、授权、模板或单据变化会阻止覆盖本地状态。轮询异常暂停记录，管理员修复后可以手动读取；不会循环重试外部创建。

本轮工程与合成CLI加真实MySQL验证通过，不等于真实手机人工审批验收；真实账号已验证模板管理、表单、部门、人员与预测，实际发送、手机决定和真实结果回写以本机联调回执为准。

整套安装恢复后关闭原生审批连接与自动读取，未发送预演取消、发送中状态改为不明，保留已发实例证据；不继承DWS授权。重新授权后仍须核对外部实际状态，不能盲目重发。
