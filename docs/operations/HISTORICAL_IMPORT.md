# 历史资料和业务单据补录

管理员可在“合同与订单 → 历史资料与补录来源”查看已导入文件的各工作表，按文字检索、查看原始行和下载原件。原件以不可变文件字节及SHA256保存，保留源列、行号和空值。资料包含完整联系方式及财务信息，原件入口仅限当前公司管理员；客户、联系人、合同、开票、回款按业务权限显示，不将原始资料开放给委托智能体。

历史补录以已授权管理员的有效会话执行一次性事务命令。导入前核对源文件摘要、合同唯一编号、客商名称/编码及人员唯一对应，核对合同金额与阶段金额、回款和开票合计，备份现有安装。审计记录来源摘要及新增对象编号，同一请求重放返回原回执；禁止重复生成单据。历史单据不伪造当前审批过程，不自动创建新业务通知。

客户经理按源人员对应，客户归其私海；合同保留原合同编号和我方签约主体。签给其他公司的合同依旧标明该主体，不代表跨公司数据库共享。客商主表未列出的甲方仅使用合同中明确的单位名称和编码补建，其余工商信息保持待补。非标准税号原值保留在备注及原件，不写入标准统一社会信用代码字段。联系人姓名为空的占位行保留在原始资料中，不虚构人员。

每条有效阶段建立回款计划；有原始开票金额与日期时建立开票记录，有回款金额与日期时建立历史回款单和对应核销关系。合同、阶段、到账及核销金额使用Decimal精确到分核对。回款单内部编号不是银行流水，开票内部编号不是税务发票号；导入回款标注历史来源，不伪造历史复核人员，不宣称银行或税务核验。

原表缺失的预计回款日、税率、税额、不含税额、发票类型及收款方式允许为空。无预计回款日的计划仍计入当前应收余额，在账龄中单列“日期待补”，不编造月度计划或逾期。正常新签约仍必须填写完整的分期日期和条款。财务阶段收款不作为交付验收完成的证明，不自动生成已完成的项目里程碑。
