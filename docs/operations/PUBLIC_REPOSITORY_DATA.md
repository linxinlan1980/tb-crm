# 开源代码与私有公司资料

公开仓库只包含程序、数据库结构迁移、操作说明和明确标识的合成测试资料。真实公司的名称与账号配置、人员、客户、联系人、合同、开票回款、日程、群标识和消息内容、原始文件、导入回执、数据库及备份保存在本机私有目录，不加入Git。

`.local/`、运行配置、生产导入/上传目录、工作簿、数据库导出及安装归档由忽略规则排除。迁移SQL只包含结构变更，不包含真实业务数据。安装包使用已提交的源码生成，不递归打包当前工作目录。

新测试只使用虚构的人名、公司、号码和金额。真实数据联调的回执保留本机，公开进度只描述通过的检查和范围，不发布原始记录、经营金额、凭据或真实群标识。发布前核对暂存文件与敏感信息匹配结果；不能把实际业务库当作测试fixture发布。
