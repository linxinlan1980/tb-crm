# 中文帐套及人员登录

登录页从本机网关取得可用帐套的中文名称；公司编码保留为后台路由键，不要求用户手工输入。仅返回名称、路由编码和用途，不返回数据库、路径、管理口令或连接配置。

人员使用唯一CRM人员编号（RY加数字）、已配置的完整手机号，或保留的兼容管理员账号登录。真实姓名只用于显示，不参与认证，重名不会误登录他人。手机号或跨字段账号出现歧义时拒绝登录；手机号和编号的失败次数归入同一人员账号预算，不能换别名绕过限制。公司范围在账号查询时即固定。

管理员在人员页面查看编号、姓名与手机号，可补录或更正手机号；重复号码拒绝，变更后撤销目标人员的旧登录会话。新增人员自动分配编号。钉钉只同步实际返回的完整手机号，脱敏/未返回的号码不猜测；当前接口可能不返回其他员工手机号，届时先使用人员编号。

人员同步不等于启用账户或授予管理权限。公司负责人明确授权后的账户启用、初始化口令和角色配置，应先备份、核对唯一人员及范围，记录操作及撤销旧会话；不修改客户归属。初始口令和真实人员清单只在本机私有资料中保管，不作为开源安装的默认密码。
