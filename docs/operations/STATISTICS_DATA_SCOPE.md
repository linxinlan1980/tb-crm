# 统计人员范围与数据权限

## 产品规则

所有现行统计入口（工作台、商机阶段看板、销售预测、回款/应收/账龄及项目月份矩阵）同时使用日期区间和人员范围。每次重新进入统计页面，默认登录本人；管理员、老板、主管也不自动切到全公司。不持久记忆上次扩大范围的选择。日期仍限制为2010年1月1日至2060年12月31日。

人员范围是筛选条件，不能授予权限。服务器将它与当前帐套、模块权限、原有逐条数据可见规则取交集。默认本人，指定人员、部门和全公司都必须明确选择；越权直接返回403，缺少必要编号、互相矛盾的参数返回400，不静默退回其他范围。

| 当前数据权限 | 可选范围 |
| --- | --- |
| 本人 / custom未授予组织范围 | 本人 |
| 部门 / 团队 | 本人、同部门人员、自己部门 |
| 全公司，或现有管理员/老板权限 | 本人、本帐套人员、部门、全公司 |

候选来自实时服务端查询；不同帐套的同名人不可跨库选择。人员展示姓名及唯一人员编号，停用人员保留标签，便于交接后核对历史业务。角色、部门或权限改变后的请求按新权限重新校验，不能用旧页面选项扩大范围。协作客户仍只按原授权访问，不因选中其负责人而得到该人的全部业务。

## 操作与归属口径

在日期选择旁使用“人员范围”：默认“本人（默认）”；有权限才展示“全公司（当前帐套）”、人员及部门。切换后重新查询、清空旧结果并重置报表分页。汇总、漏斗、趋势、负责人汇总、当前页明细及当前页XLSX/CSV导出均使用同一结果。工作台和看板跳转业务明细时携带日期及人员范围；普通业务列表保留原有可见范围，可手动启用人员筛选。

| 指标 / 对象 | 人员归属 |
| --- | --- |
| 客户、商机、合同、订单 | 当前负责人 |
| 联系人 | 所属客户负责人 |
| 项目 | 销售负责人或项目经理；同一项目只计一次 |
| 任务、行动、线索 | 执行 / 分配人员 |
| 跟进 | 记录创建人 |
| 开票、回款计划、已绑定合同回款 | 合同负责人 |
| 未绑定合同回款 | 不强行分给某个销售，仅全公司统计可计入，并单独说明 |

这是当前归属下的统计，不是历史人员归属快照；当前未收、逾期、核销也不是历史期末余额。客户建档日、预计成交日、签约日、实际回款/开票日等日期口径见现有日期说明。

## HTTP与智能体契约

`GET /workspace/statistics-options`为只读候选查询，返回`defaultRange=self`、`selfId`、`canCompany`、`owners`、`departments`；不接收帐套/身份替换参数。

工作台、报表及用于钻取的业务列表支持：

- `personRange=self`，不附带其他编号；工作台/报表省略全部人员参数也是本人。
- `personRange=person&ownerId=<唯一人员ID>`。
- `personRange=department&deptId=<部门ID>`。
- `personRange=company`，仅有全公司数据权限可用。

报表旧版显式`ownerId`或`deptId`分别按人员/部门范围处理并严格授权，不再把非法范围当作空结果。普通业务列表仅在显式`personRange`时启用统计筛选，保持业务操作列表语义。

人工MCP的`workspace.overview`、`workspace.list`、两类报表工具，HTTP报表能力及独立委托MCP共享应用服务和授权；省略人员参数不会把管理员的报表扩大到公司。独立委托仍受委托能力、预算、实时撤权及原委托人权限限制，不产生额外权限。
